本ツールは、本人が管理するメールと端末の認証操作を補助するために使用します。以下は、本ツールがアクセスする情報と利用方法の説明です。

アクセスする情報

本人の同意に基づき、Gmail APIの読み取り専用権限を使います。接続先を確認するためのメールアドレス、検索条件に合うメールの件名・宛先・受信時刻・メッセージID・本文を取得し、認証コードを抽出します。

利用目的

情報は、今回の宛先に届いた認証メールの判定、コードの抽出、古いメールや使用済みメッセージの再利用防止に使います。抽出したコードは、本人が操作対象にしたAndroidアプリの認証欄へ入力します。認証を確定したとき、コード等は認証のためにそのアプリの提供元へ送信されます。

保存場所とログ

Googleの認証トークンは本人のMac内に保存し、OSのファイル権限で所有者以外の読み取りを制限します。認証情報はプログラムの公開資料やコードリポジトリへ含めません。

メール取得処理は本文やコードをメモリ内で扱い、取得履歴には取得方式・所要時間・回数・分類したエラー等を記録します。取得履歴にはメールアドレス・本文・認証コードを含めません。一方、端末操作を支えるAppium等のローカルログには入力情報が含まれる場合があります。本人がMac内のログと端末の管理を行います。

外部への送信と人による閲覧

Gmailへの問い合わせ先はGoogleです。認証情報の更新にもGoogleのOAuthサービスを利用します。メール情報を運営者の収集用サーバーへ集めたり、販売したり、広告や汎用AIモデルの学習に利用したりしません。本人以外がメールを閲覧するための管理画面はありません。

保持と削除

匿名の実行履歴は既存の保持処理により通常14日を超えたものを整理します。認証トークンは本人が連携を使う間保持します。本人はローカルの認証情報・ログを削除できます。Gmailの元メールは本ツールから削除しません。

許可の取り消し

本人はGoogleアカウントのサードパーティとの接続から、いつでも本ツールへの許可を取り消せます。取り消し後は、再度許可するまでAPIによる取得ができなくなります。

Googleのポリシー

Google APIから受け取った情報の利用と他のアプリへの受け渡しは、Google API Services User Data Policy（Limited Useの要件を含む）に従います。

この公開サイトについて

このサイトにはメールの処理機能・問い合わせフォーム・独自のアクセス解析や広告はありません。閲覧時の通信情報は、公開基盤であるGitHub Pagesの提供者が自社の方針に従い処理する場合があります。詳しくはGitHubのプライバシー声明をご確認ください。

お問い合わせと変更

お問い合わせ先はGoogleの同意画面に表示されるアプリ管理者の連絡先です。機能や情報の扱いが変わる場合は、このページを更新します。
